## A. 文本对比度（实测值，全部不达标处）

### A1 全局次级文本色 —— 影响面最大
- 现状：`--color-text-secondary: #8a8f98`（styles/variables.wxss:18）
- 实测：页面底 **3.03:1** / 白卡上 **3.25:1**（要求 4.5:1）❌
- 用途：文章摘要（article-card）、首页简介行、"全部 ›"、meta 行等，全站引用
- 建议：浅色模式改 **`#616771`**（页面底 5.3:1 / 白卡 5.7:1 ✅）；深色模式现值 `#9aa1a9` 实测 6.88:1 ✅ **无需动**

### A2 三级文本色（信息性文字用了最浅档）
- 现状：`--color-text-tertiary: #b6bac0`；用于首页"分类 · 分钟阅读"（home.wxss:365）、section-sub（:241）、搜索 placeholder
- 实测：页面底 **1.81:1** / 白卡 **1.95:1** ❌；深色 `#6b7280` 在卡片上 **3.39:1** ❌
- 建议：meta 类信息文字升档。浅色 **`#676d76`**（4.86:1 ✅）；深色 **`#8b93a0`**（5.8:1 ✅）
- 备注：若想让 tertiary 保留"纯装饰"语义，也可以只改引用处不改 token —— 二选一，报告默认改 token

### A3 今日更新状态徽章
- 现状：白字 on `#42b45b`（home.wxss:24）；深色 `#3a9e50`（:402）
- 实测：浅色 **2.65:1** ❌ / 深色 **3.39:1** ❌（24rpx 小字需 4.5:1）
- 建议：底色统一 **`#357f45`**（白字 4.91:1 ✅），深浅两档同值，深色下可再微提亮
- 备注：注释说色值取自设计稿原图采样，改动会使 chip 比设计稿深一档 —— **需你拍板**

### A4 首页 hero 调研卡（全站最大视觉元素）
- 现状：白字白按钮 on 渐变 `#55b162 → #86cb8e → #c2e6c0`（home.wxss:56）；深色 `#3f8a4d → #56a869`（:392）
- 实测（白字）：起点 2.67 ❌ / 中段 1.92 ❌ / 末段 **1.37 ❌**；深色起点 4.24（大字✅正文❌）/ 末段 2.92 ❌
- 三个方案：
  - **a.（推荐，符合 frontend-design）标题改深绿字** `#14361f`：亮末段上 **9.75:1** ✅、中段 6.94:1 ✅，浅绿底深字反而更"green-life"、更不 AI 模板；白描边按钮改深绿字保留
  - **b. 渐变整体压深**（起点 #2e8b46、末段 #55a866 左右），白字达标但卡片变重、偏离设计稿更多
  - **c. 保持现状**，接受大字标题 3:1 线上不达标（正文 desc 仍不达标，需说明）

### A5 分类彩色标签
- 现状：article-category 22rpx 彩色文字，fallback `#4ba264`（article-card.wxml:7）；分类色来自数据层
- 实测：`#4ba264` on 白 **3.16:1** ❌（11px 小字）
- 建议：① fallback 换 `--color-primary-dark #3d8b52` 系；② data/categories 里的分类色若要当文字色用，统一压到 ≥4.5:1 档位（属数据层改动，单独拍板）

### A6 搜索框 placeholder 单独承载语义
- 现状：搜索入口无可见 label，仅靠 placeholder（1.9:1）
- 准则：Forms & Feedback "Visible labels"；占位符低对比本身可豁免 WCAG
- 建议：轻量方案——placeholder 色升到 A2 的 tertiary 新值即可，不必加外置 label

## C. 按压反馈

实测 74 个绑定 tap 的元素中 **51 个无 `hover-class`**（其中遮罩/防穿透 noop 类 7 个可不加，**实际待补 ≈44 个**）。重点：

- **有滚动内容区的列表项**：search 历史标签、download 文件操作、about 行、tip-panel 档位选择、favorite/classify/category-detail 的 tab —— 点下去**毫无响应**
- 完整清单见附录（点击行号均为文件实际位置）

建议两步：
1. **升级全局 `.hover-press`**（app.wxss:38）：`opacity: 0.85` 单档反馈弱、深色模式几乎不可辨（违反 "State contrast parity"）。改 `opacity: 0.65; transform: scale(0.98)` —— transform 不影响兄弟布局，符合 "Stable Interaction States"；为深色模式单独定义 `@media` 下更深的档位
2. **给缺失元素补 `hover-class="hover-press"`**（文本小按钮补 `hover-stay` 类只做 opacity 不缩放，避免行内缩放抖动）

## E. 质感与节奏（frontend-design 视角 —— 逐项拍板）

- **E1 箭头符号混用且是模板特征**：`›` ×4 处 vs `→` ×2 处（hero 按钮、无结果引导）。frontend-design 明确把"链接/按钮文字后附 →"列为 template chrome。建议：统一为一种（推荐都用现成的 `assets/icons/chevron.png` 图片图标，或文字按钮直接去箭头）
- **E2 11px 小字 19 处**（22rpx）：集中在 download.wxss(4)、article.wxss(≥2)、home(3)、mine(1)。"Text < 12px body" 是反模式；建议信息文字最小 24rpx，22rpx 只留给徽章
- **E3 间距脱拍**：hero 卡 `margin-bottom: 44rpx`（home.wxss:59）游离于 8 格之外，其余为 40/32/24 —— 改 48rpx（顺带拉开与"探索分类"的层级）
- **E4 硬编码色无深色覆盖**（"Token-driven theming" HIGH）：10 个文件含 hex 但无 `prefers-color-scheme` 块 —— mine / index / daily / download / article / loading / empty-state / article-list / tip-panel / article-card。其中 **index 引导页整页锁死米色 `#f3e9d8`**，全站深色下它独亮。建议逐个改为 token 引用或补深色块（工作量大，可只做 index + mine）
- **E5 hero 组合的模板感**："渐变卡 + 白色药丸按钮 + 箭头"是常见 AI 组合。若想更有辨识度：hero 标题用深绿大字（顺带解决 A4），插画作为唯一视觉焦点，按钮弱化为文字链+chevron —— "把大胆花在一处，其余保持克制"
